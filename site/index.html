Emulated systems

Three cores, one inspection bench

The project is built for normal play, debugging, and accuracy work across the Game Boy family and Game Boy Advance.

DMG

Game Boy

SM83 CPU, scanline PPU, APU channels CH1-CH4, timer, IRQ, DMA, cartridge banking, and optional boot ROM loading.

  • MBC1, MBC3 RTC, MBC5, and battery-backed RAM
  • Serial, register, text, and visual test classification
  • Hardware die and SM83 netlist visualization paths
CGB

Game Boy Color

CGB palettes, VRAM banking, double-speed behavior, HDMA, and DMG-compatible rendering paths for color hardware.

  • Acid visual tests and CGB composition sentinels
  • Palette, OAM, PPU, and STOP-mode edge-case triage
  • Commercial GBC smoke coverage in the site data
GBA

Game Boy Advance

ARM7TDMI ARM and Thumb execution, tiled and affine backgrounds, OBJ rendering, DMA channels, timers, IRQ, and cartridge backup support.

  • Modes 0-5, palette, VRAM, and OAM rendering
  • FIFO audio, SRAM, EEPROM, Flash, and RTC backup
  • Optional BIOS path with HLE fallback

Accuracy lab

The interesting part is the evidence trail

The emulator ships with runners and visual tools that make regressions observable instead of anecdotal.

Debugger and die views

CPU state, disassembly, breakpoints, watchpoints, memory, VRAM, screenshots, trace controls, save-state slots, SRAM actions, audio controls, and SM83 die views live in the ImGui debugger.

Alternative frontends

The repo includes the main SDL3 desktop frontend, lightweight builds, and a vector-rendered Game Boy frontend for inspecting the machine with a different visual language.

Current frontier

Honest accuracy work, visible targets

The open edges are tracked as specific hardware behaviors and named tests rather than vague compatibility claims.

GB/GBC

PPU and OAM edge cases

Pixel FIFO behavior, sprite timing, OAM corruption, and CGB composition remain the high-value targets for visual precision.

STOP

Mode 3 and LCD behavior

DMG-compatible ROMs on CGB hardware need careful separation between STOP semantics and palette/rendering compatibility.

GBA

Bus timing and FIFO sync

Prefetch, cartridge waitstates, affine accuracy, and audio FIFO synchronization are the next realism-heavy GBA areas.

Build and inspect

Run the emulator or reproduce the evidence

The site mirrors the repo's local workflows: SDL3 desktop builds, headless compatibility runners, and generated reports.

Frontends

make gameboy
make meu-gba
make gameboy-vector

./gameboy path/to/rom.gb

Verification

make compat-run
make game-smoke
make gba-compat-run
make shootout-run

Requirements

Use GCC or Clang, G++ for ImGui frontends, SDL3 development files, OpenGL development files, make, pkg-config, and the checked-out ImGui submodule.
