Features

💻

Pixel FIFO PPU

Accurate pixel-by-pixel rendering matching original hardware scanline timing.

🎮

Game Boy Color

Full GBC support — double-speed mode, HDMA, palette registers, and VRAM banking.

💾

MBC Support

MBC1, MBC2, MBC3 (RTC), MBC5, HuC1, HuC3, and ROM-only cartridges.

🔊

Full Audio

All 4 APU channels: square waves with sweep, wave channel, and noise.

✅

Test Suite

Passes Blargg, Mooneye, and PPU test suites for maximum accuracy.

⚡

Netlist-verified CPU

SM83 CPU validated against transistor-level netlist simulation.

Compatibility

Results from automated smoke testing across 1028 commercial ROMs
